Laser Thermal Property Characterization Using Machine Learning

Built a finite difference heat transfer solver from the governing diffusion equation to model laser induced thermal transport, then trained a machine learning model to infer material properties from the simulated data.

← All projects

Overview

Rather than reach for a commercial finite element package, I derived a 3D finite-difference heat transfer simulation directly from the governing heat diffusion equation to model laser-induced thermal transport in solid materials, working through the numerical stability constraints that come with an explicit solver.

Automated parameter sweeps across material properties generated a structured synthetic dataset, which I used to train a convolutional neural network to solve the inverse problem: given a simulated temperature field, infer the material's thermal diffusivity. The model achieved an R² of 0.98 against simulated data.
